# Cat Base Mesh

Author: artofaria.
Source: https://sketchfab.com/3d-models/cat-base-mesh-4783739c1bad4d66a302086656625f75

Converted from the user-provided Cat_Base_Mesh.usdz to OBJ using Three.js USDLoader and OBJExporter. Geometry and normals are preserved; the app supplies its own materials.

The source page displayed “Free Standard” on 2026-10-24; CC0 has not been verified.

The OBJ is bundled locally; opening the demo does not contact an external service.
